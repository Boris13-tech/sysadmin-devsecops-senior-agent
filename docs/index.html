Utiliser l'outil en direct sur votre ordinateur

Un site web ouvert sur Internet n'a pas le droit de modifier votre PC à distance (et c'est tant mieux pour votre sécurité). Pour relier cette interface à votre propre machine sans taper une seule ligne de code :

1
Téléchargez et décompressez l'archive

Téléchargez SysAdmin-DevSecOps-Senior-Tool-v1.0.0.zip puis faites un clic droit dessus → Extraire tout.

2
Double-cliquez sur Lancer-SysAdmin-UI.bat

Un petit relais local démarre sur 127.0.0.1:8765 en utilisant le moteur PowerShell intégré à Windows (aucune installation requise).

3
Pilotez votre PC depuis cette interface

Le voyant en haut à gauche passe au vert (Connecté au poste local) et tous les boutons d'analyse et de nettoyage agissent en temps réel.
